# Events

## Olos Text to CRM

These are the ones sent from OlosText to the CRM. 

### Login

* Type: The "type" property specifies the type of the message. In this case, it indicates that the message pertains to a chat login campaign.
* Timestamp: The "timestamp" property represents a timestamp value, likely indicating the time when the event occurred. The value is in Unix timestamp format, which is the number of milliseconds elapsed since January 1, 1970, 00:00:00 UTC.
* Agent ID: The "agentId" property contains a numerical value (in this case, 123) representing the unique identifier of the agent associated with the chat login campaign.
* Campaign ID: The "campaignId" property contains a numerical value (in this case, 12) representing the unique identifier of the campaign.
* Campaign Name: The "campaignName" property contains a string value ("CAMPAIGN Chat") representing the name of the campaign.
* Campaign Code: The "campaignCode" property contains a string value ("CAMPAIGN Chat") representing the code of the campaign.

In summary, this JSON object represents data related to a chat login campaign event, including details such as timestamps, agent IDs, campaign IDs, campaign names, and campaign codes. It's structured in a way that makes it easy to parse and manipulate within software applications.

Example:
```json

{
    "type":"chatlogincampaign",
    "timestamp":1714480274229,
    "agentId":123,
    "campaignId":12,
    "campaignName":"CAMPAIGN Chat",
    "campaignCode":"CAMPAIGN Chat"
}

```
